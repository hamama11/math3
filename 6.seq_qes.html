1 Sn 식의 이차함수적 해석

기본 합 공식 → n에 대한 내림차순 정리

Sn = n{2a + (n-1)d} / 2
Sn = (d/2)n2 + (a - d/2)n

현재 파라미터 적용 식 실시간 연동

Sn = 1n2 + (-10)n

이차함수 대칭축 공식 (x = -b / 2a)

축 x = 1/2 - a/d
x = 5.00

2 대칭 쌍이 성립할 조건

축이 정수일 때

자연수인 하나의 항을 중심으로 완벽한 좌우 대칭을 이룹니다.

축이 .5 형태일 때

이웃한 두 정수 항의 값이 같아지며 대칭을 이룹니다.

⚠️

축이 복잡한 소수점이라면?

이차함수 곡선은 대칭이어도, 정수 위치의 항들은 높이가 모두 엇갈려 대칭 쌍이 절대 성립하지 않습니다.

3 대수적 증명: Sp = Sq

1 Sp - Sq = 0
2 p{2a + (p-1)d} - q{2a + (q-1)d} = 0
3 2a(p-q) + d(p2-q2) - d(p-q) = 0
4 (p-q) { 2a + d(p+q-1) } = 0

서로 다른 두 항 (p ≠ q) 이므로 중괄호 안이 0이 되어야 합니다.

2a + d(p+q-1) = 0

🔗 "대칭축 = 평균" 결론 도출하기

위에서 구한 수열의 구속 조건과 1단계의 이차함수 대칭축 공식을 하나로 결합합니다.

조건식을 a/d에 대해 정리: a/d = -(p+q-1) / 2
공식대칭축 x 식에 대입: x = 1/2 - { -(p+q-1)/2 }

x = (p+q) / 2

최종 결론: S_p = S_q가 성립하려면,
대칭축 x가 반드시 두 항 p와 q의 정확한 한가운데(평균)에 위치해야만 합니다.
