1 대수적 증명: Sp = Sq

A

합 공식 등식 세우기

p{2a + (p-1)d} = q{2a + (q-1)d}
B

전개 및 이항, (p-q) 묶기

(p-q) { 2a + d(p+q-1) } = 0
C

구속 조건 도출 (p ≠ q)

2a + d(p+q-1) = 0

🔗 대칭축 공식과 결합

1. a/d 추출: -(p+q-1) / 2

2. 축 x 대입: 1/2 - (a/d)

x = (p+q) / 2

결론: 등차가 성립하려면 대칭축이 두 자연수의 산술평균에 위치해야 합니다.

2 대칭축 발생 조건 요약

축이 정수일 때

p+q가 짝수이면 축은 정수입니다.
(예: p=2, q=8 → 축=5)

축이 .5 형태일 때

p+q가 홀수이면 축은 .5로 끝납니다.
(예: p=1, q=8 → 축=4.5)

4.2 같은 소수점은?

자연수의 평균으로 만들어질 수 없는 위치이므로 이산적인 수열 내에서는 대칭 쌍이 절대 성립하지 않습니다.
