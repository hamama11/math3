상황 이미지를 보고 필요한 공식을 유추해보세요. 카드를 클릭하면 정답이 나옵니다.

📐

SAS 상황

클릭하여 공식 확인

"두 변의 길이($b, c$)와 그 사이의 각($A$)을 알 때"

코사인법칙

$a^2 = b^2 + c^2 - 2bc \cos A$
📏

SSS 상황

클릭하여 공식 확인

"세 변의 길이($a, b, c$)만 주어졌을 때"

코사인법칙 변형

$\cos A = \frac{b^2 + c^2 - a^2}{2bc}$
🎯

ASA/AAS 상황

클릭하여 공식 확인

"한 변과 양 끝 각, 또는 마주보는 쌍을 알 때"

사인법칙

$\frac{a}{\sin A} = \frac{b}{\sin B} = \frac{c}{\sin C}$
⭕

외접원 상황

클릭하여 공식 확인

"호수의 외접원 반지름($R$)을 알 때"

사인법칙 응용

$\frac{a}{\sin A} = 2R$
